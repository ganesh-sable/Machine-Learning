# K-Nearest Neighbors (KNN)

This folder contains implementations of the K-Nearest Neighbors algorithm.

## Overview
KNN is a simple, non-parametric algorithm used for both classification and regression by finding the K nearest data points.

## Key Concepts
- Distance metrics (Euclidean, Manhattan, Minkowski)
- Choosing optimal K value
- Weighted KNN
- Cross-validation

## Advantages
- Simple and easy to implement
- No training phase required
- Effective for non-linear problems
- Flexible for multi-class problems

## Disadvantages
- Slow prediction time with large datasets
- Sensitive to feature scaling
- High memory requirements

## Applications
- Classification
- Regression
- Recommendation systems
- Pattern recognition
