# Ensemble Learning

This folder contains ensemble learning methods that combine multiple models for better predictions.

## Overview
Ensemble methods combine predictions from multiple learners to achieve better performance than individual models.

## Ensemble Techniques
- Bagging (Bootstrap Aggregating)
- Boosting (AdaBoost, Gradient Boosting)
- Stacking
- Voting Classifiers
- Random Forests
- XGBoost, LightGBM

## Advantages
- Reduced variance and bias
- Improved accuracy
- Better generalization
- Robustness to outliers

## Applications
- Classification tasks
- Regression tasks
- Feature importance ranking
- Credit scoring

## Files in this folder
Find implementations of various ensemble methods and examples.
