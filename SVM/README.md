# Support Vector Machine (SVM)

This folder contains Support Vector Machine implementations for classification and regression.

## Overview
SVM is a powerful supervised learning algorithm that finds the optimal hyperplane to separate classes or predict continuous values.

## Key Concepts
- Hyperplane and margin
- Support vectors
- Kernel functions (Linear, RBF, Polynomial, Sigmoid)
- Soft margin and regularization
- Multi-class classification

## Advantages
- Effective in high-dimensional spaces
- Memory efficient
- Versatile with different kernel functions
- Good for binary and multi-class problems

## Disadvantages
- Slow training with large datasets
- Sensitive to feature scaling
- Difficult to interpret

## Applications
- Text classification
- Image classification
- Bioinformatics
- Regression problems
