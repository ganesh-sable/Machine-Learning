# Logistic Regression

This folder contains logistic regression implementations for binary and multi-class classification.

## Overview
Logistic regression is a fundamental classification algorithm that models the probability of a binary or multi-class outcome.

## Topics Covered
- Binary Logistic Regression
- Multi-class Logistic Regression (One-vs-Rest, Softmax)
- Regularization (L1, L2)
- Sigmoid function
- Cost functions and optimization

## Key Concepts
- Odds and log-odds
- Maximum likelihood estimation
- Decision boundary
- Probability calibration

## Advantages
- Simple and interpretable
- Probabilistic output
- Computationally efficient
- Works well with linear relationships

## Applications
- Binary classification
- Multi-class classification
- Probability estimation
- Medical diagnosis
- Credit risk assessment

Find logistic regression implementations and practical examples.
