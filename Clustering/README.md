# Clustering

This folder contains clustering algorithms and examples for unsupervised learning.

## Overview
Clustering is an unsupervised learning technique used to group similar data points together without predefined labels.

## Algorithms Covered
- K-Means Clustering
- Hierarchical Clustering
- DBSCAN (Density-Based Spatial Clustering)
- Gaussian Mixture Models (GMM)
- Mean Shift

## Applications
- Customer segmentation
- Image compression
- Document classification
- Gene sequencing
- Social network analysis

Explore the Python implementations of various clustering algorithms.
