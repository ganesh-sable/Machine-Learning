# Linear Regression

This folder contains linear regression models and techniques for regression tasks.

## Overview
Linear regression is a fundamental supervised learning algorithm that models the linear relationship between features and target variable.

## Topics Covered
- Simple Linear Regression
- Multiple Linear Regression
- Polynomial Regression
- Regularization (Ridge, Lasso)
- Elastic Net

## Key Concepts
- Cost functions (MSE, MAE)
- Gradient descent optimization
- R-squared and other metrics
- Assumption checking

## Applications
- Price prediction
- Sales forecasting
- Risk assessment
- Trend analysis

## Advantages
- Simple and interpretable
- Computationally efficient
- Works well with linear relationships
