# Decision Tree

This folder contains decision tree algorithms for both classification and regression tasks.

## Overview
Decision trees are versatile models that make predictions by learning simple decision rules from data.

## Key Concepts
- Tree structure and nodes
- Splitting criteria (Information Gain, Gini Index)
- Pruning techniques
- Depth and complexity control

## Use Cases
- Classification problems
- Regression problems
- Feature importance analysis
- Non-linear pattern detection

## Advantages
- Easy to understand and interpret
- Requires little data preparation
- Handles both numerical and categorical data

## Files in this folder
Find implementations of decision tree models and practical examples.
