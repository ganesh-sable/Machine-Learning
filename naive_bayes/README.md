# Naive Bayes

This folder contains Naive Bayes classifier implementations for classification tasks.

## Overview
Naive Bayes is a probabilistic classifier based on Bayes' theorem that assumes conditional independence between features.

## Variants Covered
- Gaussian Naive Bayes
- Multinomial Naive Bayes
- Bernoulli Naive Bayes
- Complement Naive Bayes

## Key Concepts
- Bayes' theorem
- Conditional probability
- Independence assumption
- Laplace smoothing

## Advantages
- Fast and efficient
- Works well with small datasets
- Handles high-dimensional data
- Simple and interpretable
- Works with both discrete and continuous data

## Disadvantages
- Assumes feature independence (often violated)
- May underestimate probabilities
- Performs poorly with correlated features

## Applications
- Text classification
- Spam detection
- Sentiment analysis
- Document categorization
- Disease prediction
